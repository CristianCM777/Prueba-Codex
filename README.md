# 🧮 Prueba-Codex

Aplicación de consola en Python que implementa una **calculadora básica** para realizar operaciones aritméticas entre dos números enteros ingresados por el usuario.

## 📌 Descripción del proyecto

Este proyecto es una base simple y didáctica orientada a practicar fundamentos de programación en Python, incluyendo:

- Entrada de datos por consola.
- Operaciones matemáticas básicas.
- Validación de división entre cero mediante condicionales.
- Salida de resultados de forma clara para el usuario.

Es ideal como punto de partida para evolucionar hacia una calculadora más completa con mejor manejo de errores y más funcionalidades.

## 🛠️ Tecnologías usadas

- **Python 3**
- Ejecución por **línea de comandos (CLI)**
- Librerías estándar de Python (sin dependencias externas)

## 🚀 Instalación

1. Clona este repositorio:

   ```bash
   git clone https://github.com/<tu-usuario>/Prueba-Codex.git
   ```

2. Entra al directorio del proyecto:

   ```bash
   cd Prueba-Codex
   ```

3. Verifica que tengas Python 3 instalado:

   ```bash
   python3 --version
   ```

> No requiere instalación de paquetes adicionales.

## ▶️ Uso

Ejecuta la aplicación desde la raíz del proyecto:

```bash
python3 app.py
```

Luego, ingresa los dos números solicitados en consola para obtener:

- Suma
- Resta
- Multiplicación
- División (siempre que el segundo número sea distinto de cero)

### Ejemplo rápido

```text
Calculadora básica
Número 1: 10
Número 2: 2
Suma: 12
Resta: 8
Multiplicación: 20
División: 5.0
```
